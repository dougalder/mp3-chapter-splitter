MP3 Chapter Splitter

A browser-based tool for splitting MP3 files into chapters with automatic beat detection or manual timestamps.

Features

  • Load MP3 files (any bitrate, mono or stereo)
  • Auto-detect chapter breaks by analyzing audio silence and dynamics
  • Paste timestamps from YouTube or manually enter break points
  • Edit chapter titles and metadata (artist, album, year, genre)
  • Real-time waveform visualization
  • Preview playback with timeline scrubbing
  • Export chapters as separate MP3 files in a ZIP archive
  • Dark mode support
  • Works entirely in your browser—no server upload needed

How to Use

Option 1: Auto-Detect

  1. Click "Load MP3 File" and select your file
  2. Open the "Auto-Detect" tab
  3. Adjust detection sensitivity if needed
  4. Click "Detect Breaks"
  5. Review the detected chapters in the table
  6. Edit chapter titles in the "Tags" tab
  7. Click "Split & Download" to export

Option 2: Paste Timestamps

  1. Load an MP3 file
  2. Open the "Paste Timestamps" tab
  3. Paste timestamps (from YouTube or manual format):
    [00:00] Chapter One
    [05:30] Chapter Two
  4. Click "Parse Timestamps"
  5. Review and edit in the table
  6. Click "Split & Download"

Requirements

A modern web browser with support for:

  • Web Audio API (for MP3 decoding)
  • File System Access API (for folder save, or ZIP fallback)
  • Canvas 2D (for waveform visualization)

Technical Details

The splitter uses frame-accurate lossless MP3 cutting (no re-encoding) and supports all standard MPEG-1/2/2.5 Layer III formats. It synthesizes proper ID3v2.3 tags and VBR headers for each output file.

See MANUAL.md for detailed documentation and README.md for developer info.
